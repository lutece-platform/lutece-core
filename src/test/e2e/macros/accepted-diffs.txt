# Macros whose rendering changes on purpose in LUT-33387: each one fixes a defect of the reference.
# One macro name per line, followed by the reason. compare-macros.py prints their differences
# but does not fail on them.
aButton    the class added by align was glued to class: "my-classd-flex" is now "my-class d-flex"
pre        id was written without its name: <pre my-id> is now <pre id="my-id">; no empty class=""
code       renders @pre, same fix
cOption    a true disabled or selected was glued to params: "disableddata-x" is now "disabled data-x"
cOptgroup  same as cOption for disabled
addToast     a stray quote followed params: data-x="1"" is now data-x="1"
initToast    same as addToast
cToast       same as addToast
cMultiselect params was written as a literal attribute named params (params=data-x="1"): it is now a real bundle of attributes
cScrollSpy   the id attribute received the class: id="${class}" is now id="${id}"
option       the id was written without a space before it and without its closing quote: <optionid="x is now <option id="x"
iconStack    id was written without the attribute name, same fix as pre
cTile        a stray "}" followed the data-bs-title attribute; title and detail were JavaScript-escaped in an HTML attribute
